# 2048 Game
  - A classic 2048 puzzle game built with HTML, CSS, and JavaScript.

# Live Preview
  - [DEMO LINK](https://artemnosachenko.github.io/2048-game/)

# Technologies Used
  - HTML5
  - SCSS
  - JavaScript

# Getting Started
  **Prerequisites**
  - Make sure you have Node.js and npm installed on your computer.

  **Installation**
  1. Clone the repository:
    - git clone https://github.com/ArtemNosachenko/2048-game.git
  2. Navigate to the project directory:
    - cd 2048-game
  3. Install the dependencies:
    - npm install
  4. Start the development server:
    - npm start

# Features
  - Interactive 4×4 game board.
  - Keyboard controls.
  - Score tracking.
  - New game and restart functionality.
  - Win and game-over conditions.
  - Responsive design.
